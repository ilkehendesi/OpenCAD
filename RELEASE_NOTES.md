# OpenCAD 0.9.0

Windows x64 development release with an English interface.

- Click or sweep across objects with TRIM. Release applies the stroke; Esc cancels the preview; one Undo reverses it.
- Open independent drawing tabs with separate layers, views, drafting settings and undo histories.
- Close tabs with Save project, Discard or Cancel; recover all open drawings after an interrupted session.
- Improved logo appearance in the header and start screen.

## Download and run

Download the attached **OpenCAD.zip**, extract the entire archive, and run **OpenCAD/OpenCAD.exe**. Keep all runtime files beside the executable. No separate Node.js or Python installation is required for this portable package.

The automatically generated Source code archives are for development and do not include the complete desktop runtime.

DWG export through the bundled LibreDWG writer remains experimental. This is not a full AutoCAD-compatible release. Automated geometry and browser checks passed; Windows executable launch and target AutoCAD acceptance have not yet been tested.
